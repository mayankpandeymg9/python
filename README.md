## 🚀 Getting Started

Want to explore the code or practice along with me? Follow these steps.

### Prerequisites

- Python 3 installed on your system.
- A code editor such as VS Code or PyCharm.
- Basic familiarity with running commands in a terminal.

### 1. Clone the repository

```bash
git clone https://github.com/mayankpandeymg9/python.git
```

### 2. Navigate into the project

```bash
cd python
```

### 3. Run a Python script

For example:

```bash
python convert_int_to_float.py
```

On some systems, you may need to use `python3` instead of `python`.

You can also explore any topic folder and run its individual Python files.

### 4. Explore NumPy

To run examples that use NumPy, install it if it isn't already available:

```bash
python -m pip install numpy
```
